# Twenty-One Blackjack Basic Strategy Game
Player vs dealer blackjack with a built-in basic strategy hint system and decision tracking.
## Features
- Standard blackjack with one deck reshuffled when low
- Hit, Stand, and Double Down actions
- "Show Hint" button reveals basic strategy advice for the current hand
- Tracks player decisions vs optimal strategy as a percentage
- Chip balance starting at 1000 with bets from 10 to 200
- CSS card display with suit symbols and color coding
## Tech
Static SPA · Tailwind CDN · Canvas/localStorage
